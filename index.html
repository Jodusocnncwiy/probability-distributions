二項分配 (Binomial Distribution)

正式定義：描述在 n 次獨立且重覆的伯努利試驗中，成功次數 X 的離散型機率分配。每次試驗的成功機率 p 固定不變。

實際生活例子：籃球員的投籃命中數（在固定出手次數 n 中，每次獨立出手命中率皆為 p，計算總命中球數 X 的機率分佈與變異程度）。

機率質量函數:

參數設定

出手次數 n:10
命中機率 p:0.30
統計量指標
平均數 E[X] = n * p:3.00
變異數 Var(X):2.10

超幾何分配 (Hypergeometric Distribution)

正式定義：描述從含有 N 個總數（含 K 個不良品）的有限母體中，採無放回隨機抽樣 n 件樣本時，樣本中包含 x 個不良品的離散型機率分配。

實際生活例子：批次品管瑕疵品抽檢（總批次 N 中包含 K 件不良品，無放回隨機抽樣 n 件，求抽到 x 件不良品的機率）。

機率質量函數:

參數設定

總批次 N:50
不良品數 K:10
抽樣數 n:10
統計量指標
平均數 E[X] = n * (K/N):2.00
變異數 Var(X):1.31

幾何分配 (Geometric Distribution)

正式定義：描述在獨立重複的伯努利試驗中，直到首次獲得成功為止所需要的試驗總次數 k 的離散型機率分配。

實際生活例子：直到首次推銷成功次數（每次獨立推銷成功率為 p，直到第 k 次才第一次成交的機率分佈）。

機率質量函數:

參數設定

單次成功率 p:20.0%
統計量指標
平均數 E[X] = 1 / p:5.0 次
變異數 Var(X):20.0

卜瓦松分配 (Poisson Distribution)

正式定義：描述在固定時間區間或空間範圍內，稀有事件平均以固定強度 λ 獨立發生的次數 k 的離散型機率分配。

實際生活例子：客服中心單位時間來電數（在固定時間區間內平均來電數 λ 的機率分佈）。

機率質量函數:

參數設定

平均到達率 λ:4.0
統計量指標
平均數 E[X] = λ:4.00
變異數 Var(X):4.00

負二項分配 (Negative Binomial Distribution)

正式定義：描述在獨立重複試驗中，為了達到指定成功次數 r 而必須進行的總試驗次數 x 的離散型機率分配。

實際生活例子：達成第 r 筆訂單所需的總拜訪數（每次拜訪成交機率為 p，當達成第 r 筆成交時，總拜訪次數 x 的機率分佈）。

機率質量函數:

參數設定

目標成功數 r:3
單次成功率 p:0.30
統計量指標
平均數 E[X] = r / p:10.0
變異數 Var(X):23.3

連續均勻分配 (Continuous Uniform Distribution)

正式定義：描述在指定區間 [a, b] 內，連續型隨機變數 X 落在任何等長子區間內的機率皆完全相等的機率分配。

實際生活例子：公車班次隨機等候時間（在發車間隔區間 [a, b] 內，乘客隨機到達的等候時間機率密度完全相同）。

機率密度函數:

參數設定

下限 a (分鐘):0
上限 b (分鐘):20
統計量指標
平均數 E[X] = (a+b) / 2:10.0
變異數 Var(X):33.3

常態分配 (Normal Distribution)

正式定義：又稱高斯分配，是一種對稱的鐘形曲線連續型機率分配，由平均數 μ 與標準差 σ 完全決定。

實際生活例子：員工年度績效考核分數（平均績效分數 μ 與標準差 σ 決定鐘形曲線的分佈）。

機率密度函數:

參數設定

平均分數 μ:75.0 分
標準差 σ:8.0 分
統計量指標
平均數 E[X] = μ:75.00
變異數 Var(X):64.00

指數分配 (Exponential Distribution)

正式定義：描述事件以固定平均發生率 λ 連續發生時，兩次相鄰事件之間的時間間隔 X 的連續型機率分配。

實際生活例子：機器設備故障間隔時間（設備平均故障發生率為 λ，兩次故障之間的時間間隔機率分佈）。

機率密度函數:

參數設定

故障率參數 λ:0.5
統計量指標
平均數 E[X] = 1 / λ:2.0 個月
變異數 Var(X):4.00
